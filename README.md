# Сетевые технологии

Материалы лабораторных и домашних работ по дисциплине «Сетевые технологии».

## Структура

- `lab` — лабораторные работы;
- `homework/homework-1` — домашняя работа 1;
- `homework/homework-2` — домашняя работа 2;
- `homework/homework-3` — домашняя работа 3.

В каждой домашней работе предусмотрены каталоги `report` и `presentation`.
